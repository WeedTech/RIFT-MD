## ✨ About

**RIFT-MD** is a WhatsApp multi-device bot built on top of the **Baileys** library. It is fast, lightweight, and easy to customize without touching the core code.

The project is fully **open source**: you are free to modify it, rebrand it, and create your own bot from this codebase, for free, without asking anyone for permission.

> 😎 Commands such as `menu`, `alive`, `antilink`, `play` and `sticker`, and the overall structure, are written to make customization as simple as possible.
